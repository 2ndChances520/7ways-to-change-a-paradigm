> **An interactive, 3D-enhanced web study guide to reprogramming your subconscious mind. Adapted by James Sopok.**

Welcome to **7 Ways to Change a Paradigm**! This project is a single-page interactive study guide designed for personal growth, small groups, and Bible studies. It explores how our subconscious habits (paradigms) are formed, what holds them in place, and providing 7 actionable, faith-based ways to shift them for the better.

---

## ✨ Features

* **🧊 3D Animated Background:** Features a soothing, rotating 3D transparent cube powered by `Three.js` that runs smoothly in the background without distracting from the text.
* **📖 Interactive Accordion Layout:** The 7 ways to change a paradigm are tucked into a clean, animated accordion menu, allowing readers to focus on one concept at a time.
* **✅ Built-in Knowledge Quiz:** At the end of the study, users can test their comprehension with an auto-grading, multiple-choice quiz designed to spark group discussions.
* **📱 Fully Responsive:** Carefully styled CSS ensures the study looks great on desktop monitors, tablets, and mobile phones.
* **⚡ Zero Setup Required:** Everything (HTML, CSS, JS) is beautifully contained within a single file.

## 📚 What You Will Learn

This study covers profound topics blending psychology and faith, including:
1. **The Subconscious vs. Conscious Mind** 
2. **The Power of Identity Statements** (e.g., *"I am a new creation!"*)
3. **Creative Visualization & Affirmations**
4. **Developing Faith and Stepping Out of Your Comfort Zone**

## 🛠️ Tech Stack

This project is lightweight, fast, and easy to host anywhere.

* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6)
* **3D Graphics:** [Three.js](https://threejs.org/) (Loaded via CDN)
